# timewarpscanme

The React + Vite app behind [TimeWarpScan.me](https://timewarpscan.me).

```sh
yarn          # install
yarn start    # dev server on http://localhost:3000
yarn build    # production build into ./build
yarn preview  # serve the production build
```

See the [main README](../README.md) for how the time warp scan works, deployment, and contributing.
